# Innugo 📁✨

**Innugo** is an Android file manager for people who want their storage explorer to feel less like a filing cabinet and more like a trusty sidekick.

It helps you hop into the folders you use most, spot recent files fast, unpack ZIPs, install APKs you find inside them, and keep an eye on storage without needing a map and a compass.

## What it does

- ⚡ **Quick Access** for common folders like Downloads, Documents, Pictures, and Music
- 📜 **Recent Files** so your latest downloads and media are never playing hide-and-seek
- 🗂️ **Browse folders** in list or grid view
- 🔎 **Search and sort** files inside a directory
- 🛠️ **Manage files** with rename, delete, share, copy-path, and create-folder actions
- 📦 **Extract ZIP archives** with progress feedback
- 📲 **Install APKs** found in archives, with optional cleanup afterwards
- 💾 **Storage overview** at a glance
- 📌 **Pinned folders and saved view mode** via DataStore preferences

## Getting started

1. Open the project in **Android Studio**.
2. Let Gradle sync the project.
3. Run the `app` configuration on an Android device or emulator.

## Permissions

Innugo asks for storage and media access so it can actually show you your files instead of just thinking encouraging thoughts about them.

It also declares permissions for:

- APK installation
- broader file access on supported Android versions
